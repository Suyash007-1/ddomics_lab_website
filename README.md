# DDOmics Lab Framework

Static React application for the DDOmics Lab website.

## Development

You need Node.js and npm.

```sh
git clone <your-repository-url>
cd ddomics-lab-framework
npm install
npm run dev
```

## Deployment

The included GitHub Actions workflow builds and deploys the site to GitHub Pages. It assumes the repository is named `ddomics-lab-framework`, so the Vite base path is `/ddomics-lab-framework/`.
